# quantforge (Python package)

MLIR-based generator of INT4 / INT8 / FP8 weight-only GEMM kernels for LLM inference, with PyTorch integration:
`quantforge.nn.quantize_model` (round-to-nearest), `quantforge.gptq.quantize_model_gptq`, `load_quantized_checkpoint`
for AWQ / GPTQ files, and the `torch.ops.quantforge.w4a16_gemm` custom op.

This package is the Python part. The kernels are generated by the C++ tool `quantforge-opt`, which you build with CMake
against LLVM / MLIR 18; see the repository README for the build and the measurements:
<https://github.com/Hieu475/QuantForge> and the notes at <https://hieu475.github.io/>.

```bash
pip install ./python[hf]            # from a clone; needs torch with CUDA
export QUANTFORGE_BUILD_DIR=/path/to/build   # the CMake build directory that contains tools/quantforge-opt
quantforge-doctor                   # checks GPU, CUDA toolchain, quantforge-opt and runs one small kernel
```
