QuantForge docs

An MLIR-based generator of GPU kernels for weight-only quantized (W4A16) matrix multiplication — the INT4-weights × FP16-activations GEMM that dominates LLM inference. QuantForge lowers

%w  = qf.unpack  %packed : tensor<KxN/2xi8> -> tensor<KxNxi8>      // 2 INT4 per byte
%wf = qf.dequant %w, %scale, %zp : ... -> tensor<KxNxf16>
%c  = linalg.matmul ins(%act, %wf) outs(%acc)

to a single PTX kernel that reads the packed weights from HBM, dequantizes them while staging tiles into shared memory, and feeds Tensor Cores (mma.sync.m16n8k16 + ldmatrix), with cp.async + double buffering.

Status: research prototype (v0.0.x). W4A16 and W8A16 GEMM with per-tensor or group-wise scale / zero point (AWQ / GPTQ checkpoints can be repacked), a skinny-M decode schedule, an autotuner; static tile-aligned shapes in the compiler, NVIDIA sm_80+. See Limitations.
